# 书柜交互实现与验收

依据《PocketWorld 书柜交互开发任务书 v1.0》。本记录区分自动检查、实际浏览器操作与调试注入，不以构建成功代替人物动画验收。真机手机未测试。

## 配置与空间

共 18 个固定书位，三层各六格，内置三本与用户书共用容量；手持书仍占原位。顶板中心从原 2.15 降至 1.55（顶面 1.59），保留底部收纳柜；层板中心高度为 0.64、0.93、1.22，厚度 0.055。书底分别为 0.6675、0.9575、1.2475，书高 0.22，层间最小净余量 0.015。

每格横向间距 0.162，中心范围 −0.405 至 +0.405。标准槽预留厚度 0.105，实际闭合书厚约 0.07；书宽沿柜深为 0.24，书脊在柜前本地 z=0.20，书后缘 z=−0.04，均在柜体深度内。抽书先向前 0.34，脱离隔板后再调整方向与打开；归位按相反路径。

人物按书位横向对准，取还位置位于柜前 z=0.54，阅读退至 z=0.96。低层屈膝最高降低骨盆 0.21，腿部逆运动学保持脚底接地。高层取书接触点在书脊较低位置；左右边缘使用靠近该书位的一只手。玩偶安放在柜侧有碰撞体的专用木台上，取书前放下，离开前拿回。

## 人物与动画

保留原 GLB 的脸、头发与服装主体，文件本身未改动。源资产是单网格，静态手臂、玩偶与衣裙存在融合接触面；直接旋转会拉扯裙边。因此运行时分离这些区域，局部重建连续双臂与手掌，补回被原手臂或玩偶遮挡的服装表面，并保留玩偶的原头部、眼罩与耳部辨识特征，补全其背面与躯干。

从九根骨骼扩至十九根：增加躯干、颈部及双侧肩、上臂、前臂、手。双臂几何体依骨骼连接，原主体继续使用蒙皮。手掌与手指为简化几何，未做逐指抓握。双向翻页分别使用相应侧手臂，另一只手承托；掌心目标与纸页绕书脊旋转使用同一个进度，过书脊后收手。普通翻页 0.8 秒；减少动态效果仍保留动作。

一本书始终是同一个实体，在书位、抽出位置和手持位置间移动，不另造手中副本。正文在翻页完成时切换并保存锚点；所有翻页输入共用边界与忙碌校验。三种受约束视角为书柜、近景、侧面。

## 内容与保存

《轨道上的日常》《窗外的地球》《微光旅行札记》各六个不同章节，为本次实现原创正文。章节边界保留，按实际可用字宽、行高与高度进一步分页；窗口变化以正文字符锚点重新定位。导入按纯文本显示，支持换行、无空格英文、连续字符与 Unicode 代理对。

正文单本上限 128 KiB，总用户正文上限 512 KiB。localStorage 使用 `pocketworld:library:collection:v1`，包含版本、修订号、书籍来源、正文、颜色、书位与锚点。所有写入通过 Web Locks 串行读取最新记录并提交，保护两个标签页的最后一个空位。浏览器不支持 Web Locks 时明确拒绝写入。失败保持原存储与表单输入；坏记录不会被默认藏书覆盖。旧 `pocketworld:library:books` 保留，合法记录在有空位时迁移，超额或损坏时拒绝覆盖。

## 验证环境与证据

桌面使用本机 Chrome / Chromium，1440×1000；触屏使用 Chromium 模拟 390×844 与 844×390，非实体手机。另以 1280×900、减少动态效果运行资源与输入恢复检查。

本地截图、录屏及结构化结果位于工作区 `.impeccable/review/`，不提交构建或录屏产物：

- `desktop.png`、`mobile.png`、`mobile-landscape.png`：最终阅读布局。
- `full-shelf-final.png`、`mobile-form.png`：实体容量及添加表单。
- `reading-s0-0.png`、`side-s0-0.png`、`forward-s0-0.png`、`backward-s0-0.png`，以及同名 `s2-0`、`s2-5`：低层、高层、边缘书位关键帧。
- `final-video/`：最终取书、双向翻页、还书连续视频；为视觉校核装入的书籍使用明确标识的测试正文。
- `touch-video/`：触屏滑动、双指隔离、横竖屏、添加与移除视频。
- `browser-results.json`：18 本实际书脊命中与双标签页容量结果；`touch-results.json`、`lifecycle-results.json`、`visual-results.json`：其余检查记录。

## 构建与资源

相对分支基线，产物 JS 由 1,407,346 增至 1,445,515 字节（+38,169），CSS 由 66,054 增至 71,272（+5,218）；全部 JS/CSS 的 gzip 合计由 434,538 增至 450,701（+16,163）。没有新增运行依赖、模型文件或纹理下载，原 `luna.glb` 仍为 8,255,228 字节。运行时新增局部双臂、手掌、玩偶补面与服装封闭几何，卸载时清理独占资源。

构建仍提示既有 Three.js vendor 超过 500 kB；不影响构建或相对资源路径。最终取还书视频约 58 秒，触屏视频约 33 秒；另保留导入与容量的功能过程视频，该较早过程不作为最终人物网格的画面验收依据。
