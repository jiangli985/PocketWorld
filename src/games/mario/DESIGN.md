# 潮汐小馆 · 美术与界面约定

以 [模块规格](README.md) 的低操作经营玩法为准。海湾、船和码头采用统一的黄昏像素风，素材来源见 [图集与街景](../../../assets/games/ski/README.md)。

## 场景与反馈

- 瓦蓝天空、暖灯渔村、灯塔与秋叶构成黄昏海湾。深色水面保留暖光倒影和浮漂所需的留白。蓝红木船的舱窗映出灯光。钓鱼人物站在船头一侧，站姿高度约为船长的十分之一。角色按短视频参考重绘为带星形发夹、蓝黑短发、白色上衣和棕色挎包的船头像素造型，握竿的手随原动作移动。
- 800×600 可见 Canvas。海湾和透明船体来自 384×384 WebP 图集。十二种鱼采用同一尺寸的像素图形，各自绘制背鳍、尾鳍、体色和高光，图鉴与上鱼动画共用。人物、海面碎波、浮漂、鱼竿、鱼线和天气覆盖层实时绘制；渲染器只消费游戏时钟。
- 人物先向后蓄力，再前倾挥竿，浮漂沿弧线飞出。入水时溅起水花，浮漂下沉回弹后随水波轻晃。等口时鱼线略有垂弧，收线时绷紧并与鱼一起靠船、离水和落到甲板。船上显示等口或收线倒计时，收线进度与鱼种设定时长同步。稀有咬钩时乌云覆盖天空，海水变暗变浑、鱼竿深弯，界面提示搏鱼键与限时。捕获特效最多 1.5 秒。减少动态效果时用稳定姿势和倒计时表示收线。

## 界面与输入

- 码头是独立的黄昏街景，蓝色渔具店与暖红色大排档并排。手绘像素字在街景加载后合入招牌底图，沿店面灯位提亮，随靠岸镜头同步缩放。招牌、橱窗和门覆盖同一个原生按钮热区，可用鼠标、触屏和键盘进入，屏幕阅读器可读出店名。门店以淡暖光和键盘焦点光点提示交互，鱼竿与厨房工作台直接在各自的小木牌上提示焦点。店内左下角用带暖窗的小渔船作为返回码头的按钮。
- 船和码头之间使用约 1.8 秒的双向镜头。靠岸时镜头随船移向岸边，船后留下像素尾浪，再抬向店面。出海时镜头从店面退回海湾。减少动态效果时直接抵达。
- 游戏页眉用带红瓦屋檐和暖灯的 Q 版小馆像素贴图。首页用带鱼形、像素金币和金色星光的描金牌呈现「现在上鱼！」，生涯和退出用独立小图标，点击开始后播放船上的音乐。等口提示、计数牌、图鉴与弹窗采用同一套细线与半透明面板。计数牌以鱼篓、金币和营业账单表现，钓鱼状态按等口、咬钩、收线和搏鱼显示对应像素图标。数字可直接读取，图标含名称提示。海湾和图鉴偏蓝绿，码头用暖灯金，渔具店用墨绿，大排档用炉火棕，收工显示暖金数字。标题的像素亮点和面板轻入场随「减少动态效果」关闭。渔具店用挂板陈列三支不同轮廓与配色的像素鱼竿，点竿查看价格和效果。大排档的小木牌贴在烤架、蒸笼与砧板上，对应整件物品的热点，每道菜的菜单卡配独立像素菜图，菜名、制作时间和收入列在图旁，窄屏可滚动查看配方和队列。
- 船底操作条使用原生按钮与点阵图形。带浮漂的竹竿用于轻敲，亮灯的木栈桥通往码头，鱼纹册打开图鉴，黄铜双竖杠用于暂停。船上方用系绳饵料袋打开鱼饵界面，用双耳金杯打开钓鱼生涯。已选鱼饵时袋角显示绿色方点。悬停或键盘聚焦显示动作文字，禁用时图标调暗。返回船上时焦点移回入口。
- 船上的夹板和罗盘图标打开任务指南，显示当前熟客、上菜进度、食材、小费和下一步指引。店内的蓝绿点单簿放在前景桌面，铜色包边配浅色账页。翻开后左页记录客人和上菜进度，右页列出还需要的份数和各道菜的材料，点选菜名进入制作。当前工作台以细小的像素热汽提示制作中，减少动态效果下显示静态热汽。稀有鱼的搏鱼面板提供五个实体点按目标，当前收线键以铜色高亮。
- 入水、试探和咬钩各有独立水纹和合成声。试探只轻动浮漂，真正咬钩时浮漂下沉、竿尖压弯，水面上显示感叹号。稀有鱼咬钩时闪电只亮一次。搏鱼按对时竿尖回弹、进度条高亮，按错时鱼线放松、进度条描边变红，最后三秒用暖红进度条提醒。渔获、售卖和换竿等事件由渔获卡、状态更新及音效表现，读屏仍可播报。文字和操作使用真实 DOM，框内按钮支持键盘并有可见焦点。
- 渔获破水时甩出像素水花，落船后卡牌从船头跃入中央，停留约 3.2 秒。普通、稀有与重量新纪录有不同的奖励音，出卡时背景音乐短暂压低。减少动态效果时保留静态标记和卡片内容。钓鱼生涯在独立的木质荣誉室呈现，灯塔侧窗和黄铜灯围住最大渔获与捕获表，配专属号角式合成乐段。
- 可见游戏区保持 4:3。窄屏重排而不缩小交互目标，主按钮最小 44×44 CSS px、长面板可独立滚动；样式只在本模块生效，不改宿主布局或 `document.body`。
