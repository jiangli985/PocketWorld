# 奶娃滑雪大冒险

奶娃自动沿雪坡滑行，跳过圆石、收身穿过树枝，在空中翻转赚取技巧分；牛来提供贴地滑行和骑乘冲撞两种伙伴能力。摔倒会让后方的豆包群逼近，豆包身体触及奶娃时结束本局。

## 操作

- W / 空格 / 触屏跳跃：轻按起跳，继续按住后空翻，松手辅助摆正。
- A / D：空中调整角度。
- S / 触屏收身：地面低姿通过树枝，空中快速下落。
- 摔倒后连续轻按跳跃：加快起身。
- Esc / 暂停：冻结本局；菜单仅含继续与返回首页。

直接访问项目 URL 的 `?game=ski` 可打开独立游玩视图，退出后回到房间；也可在房间电脑插入「奶娃滑雪大冒险」卡带。

首页 → 选择初晴雪谷、暮色松林或极夜冰原 → 无尽滑雪 → 结算，可同雪道重玩。首页退出才调用 `onExit`。

落地按头部、躯干与双板的二维碰撞体积判定。雪板端点或板底先触雪时进入连续回正和屈腿缓冲，接近竖直的雪板也可落稳。头部或躯干先撞雪、撞到障碍、落入冰隙或从下方撞上出口边缘会摔倒。石头与树枝同时检查身体和雪板的移动路径。

## 集成

保留 `mario` 卡带标识、`index.tsx` 的 `MarioGame` 默认导出及 `GameCartridgeProps`，使用 800×600 Canvas 2D。纪录键为 `pocketworld:mario:highscore`，分数和单次结算通过既有回调上报。外层停用、窗口失焦、页面隐藏会暂停，回来后需主动继续；卸载清理动画帧、输入监听和音频。

房间电脑沿用集成层的 `ComputerScreen`，支持放大、回到电脑与手机视口自动放大；独立入口使用 `CartridgePlayer`。`?dev=mario` 也可直达滑雪游戏。游戏 CSS 限定在自身类名内，无新增依赖。

奶娃动作 SVG 在加载时采样并缓存；豆包采用原图第二行八帧；牛来使用已有双形态序列图。仅绊倒和被豆包抓住时触发笑声，从原始 WAV 开头播放三秒；翻转不播放笑声；骑乘播放完整 `niulai.wav`。失败素材提供备用人物与重试入口。

游玩姿势采用 `assets/naiwa/ski-volume-rig.svg`，保留原身体轮廓与表情，重画屈腿、鞋底和双板连接，并分开控制身体、腿与雪板。收身通过前倾和屈腿降低高度，碰撞与绘制共用旋转中心和姿势参数。分层素材失败时加载原动作作为降级。
