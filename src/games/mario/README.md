# 任务二：马里奥横版闯关小游戏 (`src/games/mario/`)

## 模块职责
实现可嵌入房间电脑屏幕内的横版平台跳跃闯关小游戏，对外默认导出符合 `GameCartridgeProps`（见 `src/types/game.ts`）的 `MarioGame` 组件。

## 核心验收要求
1. **入口与隔离**：在 `index.tsx` 默认导出 `MarioGame`，使用逻辑分辨率 `800 × 600` 的 Canvas 2D。组件卸载或 `isActive === false` 时按 `agent.md` 清理循环、定时器、监听与音频，避免影响房间。
2. **四关与选关**：提供 4 个内容有明显差异的完整固定关卡，均可直接选择；保留平台碰撞、顶砖块/问号箱、金币与强化道具、至少两类敌人及终点旗杆结算。主题、机关与具体数值由队员发挥，不能用重复布局凑关数。
3. **页面与操作**：首页提供「开始游戏」与「退出」；开始后先选关。WASD 操作，A/D 左右、W 跳跃，S 的动作自行设计并说明。游玩中 Esc 立即暂停并只显示「继续游戏」「返回首页」；继续保留本局进度，返回首页结束本局。Esc 不得触发房间返回。
4. **状态联动**：通过 `onScoreChange` 上报分数，通过 `onGameOver` 上报通关/失败结果。游戏内部返回首页不调用 `onExit()`；首页「退出」才调用该接口，返回电脑游戏选择界面。最高分键为 `pocketworld:mario:highscore`。
5. **轻量交付**：保持独立入口以支持外层按需加载；不新增大型引擎，资源压缩复用，限制特效对象数量。遵守根目录 `agent.md` 与 `spec.md` 第 3 节，验证四关可完成、暂停恢复及反复进出无后台任务残留。
