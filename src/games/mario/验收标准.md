# 潮汐小馆 · 替换验收标准

这是 [mario 模块](README.md) 的长期回归与发布标准，不是通过记录。独立验收锁定 PR 的最终 commit SHA，在干净独立 worktree 运行；不改变开发者分支。发现基线已存在的问题，与候选对照后单列，不借钓鱼替换扩大范围。

## A · 玩法与生命周期

1. 使用隔离浏览器档案，进入候选 `?dev=mario`。新档开始后不轻敲，确认第一条鱼能自动捕获并点亮图鉴。从船上到码头，点击「深海渔场大排档」备四份普通寿司（最多 3 单，分批入列），观察完成才入账。凑齐 20 金币后返回码头，在「渔具店」买 Lv.2，下一竿缩短。检查店铺返回码头、码头返回船上，以及窄屏下招牌点击区和店内滚动。支出只减可花金币，不减本趟营业额。
2. 开始一笔订单，暂停、切后台或停用超过原制作时间；恢复不立即补卖。拔卡/刷新后保留未售订单和进度；已售订单不再扣鱼或发钱。收工只回调一次，返回首页不拔卡，只有首页退出请求退出。停用时未拦截宿主按键，空格长按或触屏点击不重发。
3. 用旧滑雪键 `pocketworld:mario:highscore` 放一个明显的旧值。试玩/房间内均不应读它为钓鱼最高分；创造钓鱼记录后验证只更新 `pocketworld:mario:highscore:v2`，旧值不变。测试损坏、未来版本、拒绝存储和重新装载；只在隔离档案里注入存档。核对休眠时没有任何离线时间补算。
4. 运行 `npm run typecheck` 与对应 `*.test.mjs`；确定种子的 30 分钟有效游戏测试验证鱼篓 ≤32、订单 ≤3、账实一致、统计不无限积累。回归暂停、失焦、静音、StrictMode、按键移交、单次结算和过期音频回调。替身只证明受测逻辑，不作为真实浏览器或性能证据。

## B · 旧卡替换与网络边界

1. 普通房间仍是两张卡，旧 `mario` 架位上显示《潮汐小馆》名称或对应徽标；选卡、近景拖入、槽外归位、收起暂停后恢复、拔出与换 `shooter` 一一验证。无第三张卡、槽位或新模型；故障/取消后 `Esc` 可退，晚到的加载不会重新挂载。若旧基线已有全景直接聚焦而未先走近，记录现状，不把它列作新增玩法要求。
2. 验证旧 `?game=ski` 房间快捷链接打开替换后的 `mario`，`?dev=mario` 独立进入真实卡带，`?dev=shooter` 与团团魔法录仍正常。证明普通房间首屏前未请求钓鱼专属产物、插入 `mario` 后才加载；独立试玩不请求房间、Three.js 或 GSAP。房间、两个调试入口分别用冷上下文检查，不用 HMR 流量判断。
3. 至少用桌面和窄屏验证 4:3、拖错归位、加载错误与退出。归位、窗口隐藏和回到电脑不得把同一局当作新一局。加相应 `media-exit.test.mjs` 回归，沿用现有 `cartridge-motion` 和 `screen-layout` 验证；实现改动的发行候选通过 `npm test`。

## C · 轻量与发布门槛

| 指标 | 门槛与测法 |
|---|---|
| JS/CSS | 正式卡带专属 raw ≤40 KiB、gzip ≤16 KiB。按候选生产构建的模块可达依赖或冷请求清单逐文件统计，原始字节与 `zlib.gzipSync` 字节分别累计，不看 JS 字符数或任取 `index-*.js`。不计既有共享 React、独立调试外壳。 |
| 首次游玩 | 房间插卡前 0 个钓鱼专属请求；游戏首玩资源含可选图集 ≤72 KiB raw、≤3 个专属请求。依赖、GLB、字体、外部音频新增均为 0。内联图只计承载文件。核对开始钓鱼时未加载街景，首次靠岸才请求街景。 |
| 有界运行 | 捕捞与订单固定上限；动效 ≤50 个，寿命 ≤1.5 s；非事件 HUD ≤10 Hz，存档与最高分合计 ≤4 KiB，合成音效并发 ≤4。无逐帧 React 更新或落盘。 |
| 循环与释放 | 独立页装卸 10 次，房间实体插拔 10 次；至少启动一次音效、覆盖暂停/失焦/恢复。暂停没有游戏待执行 RAF、计时器或活跃音源；卸载也没有残留的游戏全局监听或活跃 AudioContext。只统计钓鱼模块，不把房间自己的循环算进去。 |
| 真机同屏 | 记录中低端 60 Hz 手机、浏览器、画质、视口和采样条件。各取房间空闲基线和房间+钓鱼玩 60 s；至少含等口、收鱼、备货、售出和一次切面板。钓鱼实际 `step + draw` p95 ≤4 ms；正常可见时的浏览器 RAF 间隔 p95 ≤20 ms。刻意跳绘不是浏览器丢帧；桌面模拟不替代真机。 |

## 交付与结论

开发者交任务编号、PR、最终 SHA、环境、命令及结果、最短复现和未验证项；包体/网络给逐文件清单与触发时机，性能给样本与 p95。证据放 PR 或仓库外。独立验收人以同一 SHA 复测并给出「通过 / 不通过 / 未验证」；缺少真机、真实装卸或冷网络证据不能签正式发布通过。阻塞发现给出预期、实际、复现、影响和负责任务，修复后以新 SHA 复验。不自行合并。
