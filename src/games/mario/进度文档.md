# 马里奥模块进度

## 当前玩法方案

当前准备采用侧视无尽滑雪玩法。主角使用黄色奶娃，后方大量豆包奔跑追赶，主角与豆包身体接触后结束本局。黄色牛来承担企鹅和雪怪两种伙伴用途，分别提供贴地滑行加速与骑乘冲撞能力。上述方案处于素材准备阶段，玩法与能力待实现。

## 已具备的功能

尚无可运行的游戏功能。公共 `GameCartridgeProps` 类型和模块交付规范已定义，`MarioGame` 入口尚未实现。

`assets/niulai/` 已依据用户提供的「牛来原皮」参考图重新绘制黄色牛来，提供贴地滑行与冲撞奔跑 SVG 动画，以及可供 Canvas 2D 播放的两套八帧 SVG 序列图。参考与绘制说明、上游许可、帧尺寸与使用说明均保存在该目录。四份 SVG 合计约 57 KiB。
