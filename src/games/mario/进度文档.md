# 奶娃滑雪大冒险模块进度

## 当前玩法方案

按用户确认的滑雪设计方案完成侧视无尽滑雪：黄色奶娃为主角，多名豆包从后方追赶，黄色牛来提供滑行和冲撞双形态。替代最初的横版马里奥方向，保留 mario 标识、MarioGame 默认导出、GameCartridgeProps、800×600 画布和 pocketworld:mario:highscore。

## 已实现

- 首页、三条雪道选择、游玩、暂停与结算，可重玩或返回首页；首页退出调用 onExit，单局只上报一次 onGameOver。
- 自动滑行、长按跳跃与后空翻、松手摆正、A/D 微调、S 收身、快速下落、按键缓冲与离地宽限、摔倒后连续轻按起身。
- 初晴雪谷、暮色松林、极夜冰原：共用物理，不同配色、速度和安全片段；圆石、树枝、跳台、冰面、冰隙救援坡、金币与伙伴。
- 背景山体采用连续轮廓并填充到画面底部，避免下坡露底与拼接切边；远景松林落在连续雪坡上，树木和雪纹按世界位置滚动，移除主角附近树木突然消失。
- 豆包固定八名，采用第二行八帧跑步与错相站位；身体圆组和运动路径扫掠检测排除雪尘、透明边缘，高速经过也可命中。
- 牛来滑行加速并吸收一次普通撞击；冲撞形态撞碎圆石，树枝和冰隙仍有效。接力不叠加时长或护盾，骑乘不能免疫豆包。
- 安全落地才计翻转分，连续翻转落地倍率最高×3，摔倒清空；金币和距离计分，最高分本地保存。
- 奶娃动作 SVG 加载时预采样为可冻结帧；骑姿剥离企鹅和双板后组合牛来，后空翻仅由物理旋转。素材缓存、加载失败备用人物与重试入口。
- 仅绊倒和被抓住触发原版笑声前三秒，翻转不触发笑声，同类重复触发重新播放；骑上牛来播放完整 niulai.wav。静音立即停止声音，暂停挂起 AudioContext，卸载关闭。
- 键盘与触屏双键、减少动态、失焦/页面隐藏/外层停用自动暂停；返回后等待继续，恢复不补算停顿时间。
- 电脑卡带改名「奶娃滑雪大冒险」，房间入口使用集成层放大游玩视图；`?game=ski` 可直接打开同款游戏画面，退出回到房间。其他游戏和人物模型保持各自边界。

## 验证结果

- `node --test src/games/mario/engine.test.mjs src/games/mario/sound.test.mjs src/games/mario/renderer.test.mjs`：27项通过。
- 三雪道各180秒自动操作测试可完成全部片段，无无敌保护、零摔倒、零失败；三条各30分钟资源边界测试通过。后者隔离失败因素，只证明对象回收，不能解释为自然存活时长。
- 实体不超过72、粒子不超过80、豆包固定8；速度上限470。正常追赶净距约200～260像素，伙伴可暂时拉开，无操作分别约26/31/27秒被身体接触追上；首次绊倒可自然恢复。
- 音频事件测试确认只有绊倒、被抓住播放笑声，翻转/落地/金币不播放，骑乘保持牛来音效。
- 三雪道新增轮廓覆盖与接缝检查；Canvas 像素对比确认底部不再露空，并检查多个滚动周期边界。新标题七字字体子集宽约426px，小于640px标题区域。对比图见 [背景修复前后](./review/background-comparison.png)（左旧右新，备用人物绘制）。
- 音频测试检查三秒source.start时长、完整牛来音效、重复音效停止与断开、静音、暂停、卸载中断加载。
- TypeScript 和生产构建通过。游戏 JS约41kB（gzip约16kB）；专属运行资源约1.86MB，按选中卡带加载。既有Three.js分包较大警告仍存在。
- 本次浏览器查看改名后的桌面首页、三雪道选择和暮色松林开局，角色正常显示；手机布局与后续完整交互未完成复验。

功能已完成并可本地游玩。本次浏览器查看了改名后的桌面首页与暮色松林，后续浏览器控制连续超时；最终背景另经三雪道 Canvas 对比渲染检查。当前版本的手机布局、暂停/恢复、反复插拔、完整结算和手机长按/松手仍待完整浏览器验收；音频触发、时长与生命周期有代码测试，未宣称完成听感验收。
