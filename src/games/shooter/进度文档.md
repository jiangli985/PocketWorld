# 射击模块进度

## 当前玩法方案

本模块已确定推翻初始的自动射击无尽生存玩法，重做为「弹球失控」：短局 Roguelite 弹球 + 连锁构筑，不新增卡带，也不保留打飞机玩法。单局目标约 3 分钟，玩家用鼠标或触屏拖动瞄准、松开发射，让球在场地内反弹并击中敌人；清完一波后从 3 个随机强化中选 1 个，通过分裂、连锁和范围效果形成高密度碰撞反馈，争取更高分。

变更原因：相较自动射击，瞄准发射和可见的连锁反应更直观，打开网页后能快速上手，首球即有反馈。首版范围为一张地图、三种敌人、六个强化技能和一场短局挑战，使用几何图形、粒子与程序化音效保持轻量。战机移动操作不再适用，操作说明随玩法更新。

## 集成约定

本次只改玩法，接口和集成方式保持不变，无需修改公共类型：

- 代码位于 `src/games/shooter/`，入口 `index.tsx` 默认导出 `ShooterGame`，实现 `GameCartridgeProps`；`GameId` 继续使用 `shooter`，调试入口为 `?dev=shooter`。
- 画布为 800 × 600 Canvas 2D。「弹球失控」只是显示名，内部标识不改名。
- 最高分键为 `pocketworld:shooter:highscore`，历史成绩键为 `pocketworld:shooter:history`；两者均为必做，历史记录设固定条数上限，首页展示最高分与历史成绩。
- 首页提供「开始游戏」与「退出」，HUD 显示得分、最高分和状态，右上角提供「暂停 / 退出」按钮。保留 `P` 键暂停；暂停时冻结全部对象、计时与特效，恢复后不补算暂停期间的时间。
- 分数变化时调用 `onScoreChange`；每局只调用一次 `onGameOver`，`victory` 按实际胜负上报。首页「退出」调用 `onExit()`，内部返回首页不调用。
- 音效响应 `isMuted`；卸载或 `isActive === false` 时清理动画循环、定时器、事件监听与音频，首页自动演示同样停止。捕获的方向键或空格按规范隔离。
- 拖动瞄准的鼠标与触屏事件不得传到外层，避免带动 3D 房间视角。
- 球、敌人、粒子等对象设置数量或寿命上限并及时回收。

需要队长协调的事项：桌面图标显示名改为「弹球失控」，在集成时处理。
