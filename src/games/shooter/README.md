# 任务三：打飞机太空射击小游戏 (`src/games/shooter/`)

## 模块职责
实现可嵌入房间电脑屏幕内的小游戏，对外默认导出符合 `GameCartridgeProps`（见 `src/types/game.ts`）的 `ShooterGame` 组件。太空射击是初始方向，允许重设计甚至推翻核心玩法，技术与集成约定保持稳定。

## 核心验收要求
1. **入口与隔离**：在 `index.tsx` 默认导出 `ShooterGame`，使用逻辑分辨率 `800 × 600` 的 Canvas 2D。组件卸载或 `isActive === false` 时按 `AGENT.md` 清理循环、定时器、监听与音频。
2. **玩法自主设计**：初始参考为统一偏高难度的无尽生存、自动射击、多类敌机、击落计分及强化/炸弹掉落；可以整体重做，在 `进度文档.md` 和 PR 中说明当前方案。保留 WASD/方向键移动等既有操作约定，新增操作必须有说明，涉及集成变动先由队长协调。
3. **首页与记录**：首页提供「开始游戏」「退出」，显示最高分与历史成绩。最高分键为 `pocketworld:shooter:highscore`，历史列表键为 `pocketworld:shooter:history`，历史条数必须有固定上限。支持 P 或按钮暂停，暂停时冻结游戏进度并停止射击。
4. **状态联动**：通过 `onScoreChange` 上报实时分数与最高分，通过 `onGameOver` 上报实际结算结果，每局只上报一次；初始无尽模式死亡时 `victory: false`。游戏内部返回首页不调用 `onExit()`；首页「退出」才调用该接口，返回电脑游戏选择界面。
5. **轻量交付**：保持独立入口以支持外层按需加载；不新增大型引擎，限制敌机、子弹、掉落物与粒子数量或寿命，回收离屏对象。遵守根目录 `AGENT.md` 与 `SPEC.md` 第 3 节，验证高弹幕场景、长时间运行及反复进出无持续增长的对象或监听。
6. **进度与 PR**：维护本目录 `进度文档.md`，写清已有功能、当前阶段和剩余工作，直接更新当前状态并清理冗余，不累加日志。每次提交前核对，PR 必须附本次提交简介与文档链接；仅通过功能分支 PR 交付，由队长审查合并。
