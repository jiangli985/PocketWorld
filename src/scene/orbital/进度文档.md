## 2. 本轮具体改动

### 2.1 连续操作、事务和镜头

`useWorldController.ts` 仍沿用准备、进入/离开、提交、返回和错误状态，不重写整个交互系统。

1. **灯绳快速拉两次**：第二次按用户已经看到的状态计算，而不是先回滚后再次读取旧状态。`toggle`、`open`、`sleep`、`sit` 和 `turn-page` 保留这一意图；失败仍可回滚到事务快照。
2. **开门后立刻取盒子**：取出收纳盒时保证柜门处于打开状态；关门时同时收回盒子。修复“盒子出来但门关回去”的不一致。
3. **坐卧互斥**：躺下解除椅子占用；坐下解除床占用和床特写；跨舱解除坐卧状态并触发适用的唤醒回调。
4. **睡眠失败回滚**：还原对象状态时也恢复睡眠会话引用。
5. **快速翻页**：进入阅读的镜头过渡尚未结束时翻页，仍保持书本打开及阅读焦点。
6. **普通物品操作不抢镜头**：开抽屉、翻页等不改变焦点的动作不再把用户视角强制复位。
7. **观景舱书本特写**：补上书架位置差异，镜头目标与实际书本对齐。

状态探针运行在浏览器内的隔离 React 根中，调用实际控制器；它不是修改主场景状态的替代验收。柜体、床、椅子等另有真实鼠标操作验证。

### 2.2 手机输入

- 修复竖屏首次加载时使用错误相机的问题，首屏按宽高比计算视距。
- 用容器上的原生触摸捕获统一接收画布与 Drei HTML 书页事件，避免不同 React 渲染根造成返回手势失效。
- 双指轻触返回要求短时、无明显位移；有移动距离的捏合不会误触返回。
- 书页设置横向手势归应用、纵向滚动归浏览器，修复滑动被浏览器 `pointercancel` 取消的问题。
- 多指操作不再被当成单指翻页；移动端纸面字号和提示可读性已调整。
- 没有新增可见按钮。文件选择由空白唱片触发隐藏的原生文件输入。

### 2.3 家具、材质和资源管理

- 椅子坐垫和靠背使用中心鼓起、边缘收薄的软垫曲面，而非仅调整盒子颜色。
- 新增 `Materials.ts`：木材用共享程序化木纹，床品和椅垫使用共享织物凹凸材质；保留既有配色。
- `Tube` 改为按稳定形状参数复用几何体，并清理独占几何资源；不因父组件每次重绘都重建。
- 床品和新增软垫也显式清理独占几何；共享材质不随单个实例误释放。
- 保留已接入的盆栽与抱枕 GLB。未使用的扶手椅仍保留在资源目录，本轮没有删除它。

### 2.4 绘制优化

- 保留地板每块板的轮廓、拼缝和颜色，合并为带顶点色的几何体，而非 68 个独立绘制对象。
- 33 个重复键帽改用 `InstancedMesh`，保留位置和颜色区别。
- 不活动的舱室不绘制，切换时再显示相关场景。
- 未新增后处理依赖、未提高 DPR 或阴影贴图规格。

### 2.5 宇宙光照与素材

- 地球地表和云层已从 NASA SVS 官方地址取得，替换原有授权来源未确认的 three.js 示例文件。
- 海面高光遮罩由新地表图按蓝水颜色近似生成；不是科学级海陆分类或水深数据。
- 地球云层使用 GEOS-5 模型可视化的一帧，不是实时卫星天气。地表、云层、星图也不是同一时刻的观测。
- 地球与舱室共用太阳方向。修复观景舱平移后定向光仍指向世界原点的问题：光照目标现在随舱室挂载。
- 这是有真实资料来源和一致光照方向的艺术化轨道场景，不是轨道动力学、人工重力或物理大气散射模拟器。

## 3. 功能与实际验证清单

“通过”只指下表写明的验证路径，不扩展成所有浏览器、所有手势、真实音质或长时间稳定性均已通过。

| 功能 | 当前实现 | 已完成验证 | 限制 |

| 盆栽 | 触碰后增加照料状态与水滴提示 | 点击与水滴节点出现 | 没有生长模型或完整浇水动画 |

| 音箱 | 旋钮静音/恢复 | 鼠标拖动，静音状态往返 | 不是连续音量旋钮 |
| 后台播放 | 音频引擎独立于舱室和焦点 | 退出唱机及两舱往返后保持播放 | 未验证手机锁屏、后台节流或系统中断 |
| 电脑/游戏 | 卡带飞入、缺失模块提示、拔出返回 | “弹球失控尚未接入”与拔卡返回 | 游戏本体不存在，玩法、得分、暂停回调未能实测 |

## 6. 性能与构建结果

### 6.1 可比较的测量

- 同一桌面生活舱机位：绘制次数从 **414 降到 315**，减少 99 次，约 **23.9%**。
- 三角形从约 173,916 变为 176,996；优化重点是合并绘制，而软垫曲面增加了少量三角形。不能声称三角形数量也下降。
- 干净初始状态测得几何体 258、纹理 12。
- 在已经导入歌曲、走过两舱的状态下，连续四轮打开/退出日记，几何体数量 **343 → 343**。这证明该复现路径下不再持续分配，不代表长期压力测试完成。
- 其他状态曾测得 298 次绘制，但唱片架页数、可见物体与姿态不同，不用该数值冒充同机位优化结果。
- 不报告未经测量的 60 FPS 或实体手机性能。

### 6.2 构建与检查

- `npm run build`：通过，包含 TypeScript 检查和 Vite 生产构建。
- `git diff --check`：通过。
- `npx impeccable detect src/scene/orbital`：命令成功，19 个文件按正则规则扫描；未运行需要页面解析的低对比度/小字号规则，不把它当完整可访问性通过。后续新增/修改需按范围复检。
- Three.js vendor chunk 仍约 **1,113.39 kB**，gzip **313.88 kB**，仍有超过 500 kB 的构建警告。没有通过修改警告阈值掩盖问题。
- 最终无头浏览器回归路径没有新增应用运行错误。开发中出现过测试脚本用错选择器、过时相机引用及热更新保留旧 ref 形状的问题；已重新加载后复测，不把旧日志混作最终错误。

## 7. 验收方法与边界

### 已验证

1. 真实鼠标：抽屉、柜门、收纳盒、床、椅子、唱片、旋钮和舱门。
2. 真实键盘：角色移动/跳跃，日记、日程、书籍快捷入口及双向翻页。
3. 浏览器文件上传：临时生成的测试 WAV；该测试文件不进入仓库。
4. 拖放处理：有效音频和无效文本文件，验证播放或明确错误提示。
5. Chromium CDP 触摸事件：双向滑动翻页、双指返回、捏合不误返回。
6. 控制器隔离探针：快速拉灯绳、快速取盒、关门收回、坐卧互斥、跨舱唤醒回调、适配器准备失败回滚。
7. 数值检查：跨舱前后的太阳单位方向均为约 `[-0.534522, 0.801784, 0.267261]`。
8. 循环资源检查：四轮访问日记后几何体数不增加。

### 未验证或不属于本轮完成范围

- 实体 iPhone/Android、Safari、软键盘遮挡、锁屏音乐和低端 GPU。
- 完整屏幕阅读器流程。提供快捷键说明不等于所有物体都具有完整辅助技术可达性。
- 远程日记/日程适配器的数据持久化和断网重试。
- 长时间运行、多种导入音频格式、所有异常网络与资源加载场景。
- 真实游戏的开始、暂停、得分、结算和最高分回调。
- 完整轨道结构、重力计算、实时天气或科学可视化精度。
