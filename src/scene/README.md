# 任务一：3D 等轴测房间建模、镜头动画与音乐光盘系统 (`src/scene/` & `src/components/music-player/`)

## 模块职责
1. **3D 等轴测箱庭房间**：非像素风 Stylized 3D 剖面小房间（两面墙 + 地板 + 窗户体积光 + 书桌电脑 + 音乐播放器 + 沙发/植物装饰）。
2. **相机推进与物品注册表**：基于 `InteractableItemConfig` 注册可交互物品，点击电脑或音乐播放器时触发平滑推镜过渡动画。
3. **音乐播放器与光盘转化**：内置预设曲目，并支持用户拖入/选择本地音频文件（`.mp3/.wav/.flac`）实时压制生成专属音乐光盘、播放入仓旋转动画与房间背景音乐律动。
