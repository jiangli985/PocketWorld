# 提示字体

`pocketworld-prompt-rounded.woff2` 供未安装系统幼圆的设备使用，来自简体狮尾圆体 2.142 的 Medium 字重。为轨道居住舱提示保留非游戏 TypeScript 源码中使用的字形与可打印 ASCII，并将字体系列重命名为 PocketWorld Prompt Rounded。未收录的字符由系统字体补足。[上游字体](https://github.com/max32002/swei-gothic/tree/2.142/WebFont/CJK%20SC)

字体采用 SIL Open Font License 1.1，许可随站点发布。[许可与版权](../public/licenses/pocketworld-prompt-rounded-OFL.txt)
