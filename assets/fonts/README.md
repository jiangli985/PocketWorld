# 提示字体

物品提示、左下角快捷操作和键帽优先使用设备已安装的方正粗黑宋简体，其次使用系统幼圆。方正粗黑宋简体通过 CSS `local()` 加载，随站点嵌入时需取得相应网页字体授权。[方正字库授权说明](https://www.foundertype.com/index.php/FontInfo/licensing/id/195.html)

`pocketworld-prompt-rounded.woff2` 用于缺少上述本地字体的设备，来自简体狮尾圆体 2.142 的 Medium 字重。为轨道居住舱提示保留非游戏 TypeScript 源码中使用的字形与可打印 ASCII，并将字体系列重命名为 PocketWorld Prompt Rounded。未收录的字符由系统字体补足。[上游字体](https://github.com/max32002/swei-gothic/tree/2.142/WebFont/CJK%20SC)

字体采用 SIL Open Font License 1.1，许可随站点发布。[许可与版权](../public/licenses/pocketworld-prompt-rounded-OFL.txt)
